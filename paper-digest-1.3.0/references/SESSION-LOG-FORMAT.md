# SESSION-LOG-FORMAT.md

`./sessions/NNNN-slug.md` 记录每次会话，供下次接续与进度审计。

## Template

```md
# {日期} · {模式} · {主题}

## 目标
- 本课只练：{一个技能点}
- 完成标准：{可观察}

## 复习
- 到期项：{ids}；结果：{对/错}；错题：{ids}

## 主体
- 范例：{用了哪个 worked example}
- 练习：{任务与用户产出摘要}
- 反馈：{阻断/改进/润色各几条；错误码}

## 用户表现
- 掌握证据：{复述/改写/判断的原话摘要}
- 卡点：{…}

## 落盘
- digest/lesson/queue/mastery/error/learning-record：{路径或"无"}

## 下次
- 模式：{…}；主题：{…}；先复习：{ids}
```

## Rules

- 每次会话必须写；没有日志视为没发生。
- 只记证据与决定，不抄聊天记录。
- 下次会话开始先读最近一条日志与队列。
