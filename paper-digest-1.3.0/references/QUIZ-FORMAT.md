# QUIZ-FORMAT.md：检索练习与测验

## 一、题型（至少覆盖 3 类）

| 题型 | 目的 | 例子 | 反馈 |
|---|---|---|---|
| **自由回忆** | 存储强度 | "不看笔记，写出本文 3 条贡献" | 对照答案要点，自评 0–3 |
| **判断/辨析** | 概念边界 | "这条 claim 的证据强度是充分/部分/不足？" | 立即对错 + 理由 |
| **纠错** | 写作规则 | 给一句坏句，问属于 E1–E8 哪类 | 错误码 + 修法 |
| **改写** | 产出能力 | "把这句话改成一句一意、无垂悬" | rubric 分层反馈 |
| **迁移** | 应用 | "如果把它的方法搬到你的项目，先改哪一步？" | 对照迁移动作清单 |
| **teach-back** | 教别人 | "用 3 分钟讲清 claim-evidence 关系" | 讲不清退回 |

## 二、命题规则

1. 一题一个概念；选项等长、正确项位置打散；干扰项是"精确错误"（可指出错在哪）。
2. 不靠格式泄露答案；答案与解析分离；解析必须引用来源或规则。
3. 每次会话 6–10 题：3–4 道到期复习 + 2–3 道新学 + 1 道迁移/teach-back。
4. 难度：先认（辨析）→ 再回忆（自由）→ 再产出（改写/迁移）。
5. 答错必须记入 `ERROR-LOG.md` 并排回 D1。

## 三、掌握与间隔

- 单题掌握：0 不会 / 1 提示后能答 / 2 独立答对 / 3 能解释为什么。
- 连续 3 次（D1/D3/D7）≥2 → 退役；否则重排。
- 复习会话必须交错（阅读概念 + 写作句式 + 论文证据），不要只刷一篇。

## 四、HTML 约定

- `data-quiz` 容器；每题 `data-qid`；选项 `data-correct="true|false"`；解析放 `.explain`（默认隐藏）。
- 自由回忆用 `<textarea data-recall>` + "对比答案"按钮。
- 结果写回 `./review/SESSIONS.md` 与 `./review/QUEUE.md`（由 quiz-master 汇总）。
