# LEARNING-RECORD-FORMAT.md

`./learning-records/NNNN-slug.md`：决策级学习记录（非日志）。记录"现在已知什么、它改变了后续怎么学"。

## Template

```md
# {这次理解/确立了什麼}

{1–3 句：理解了什么（或确立了哪些先验知识），以及为什么影响后续。}

## 掌握证据（可选）
- {复述/改写/迁移动作/teach-back 的原话摘要}
- 对应技能级：{R?/W?}；掌握等级：{0–4}

## Implications（可选）
- 解锁：{…}
- 排除：{…}
- 下次：{…}
```

## 何时写

1. 用户对非平凡内容展示了真实理解（能复述、指出证据强度、判断失效边界）。
2. 用户披露先验知识（读过/做过什么，深度如何）。
3. 误解被纠正（最高价值）。
4. 方向调整（先确认，再改 agenda）。

## 不算

- "读过/讲过"；已在 digest/glossary 的重复内容；逐篇阅读日志。
- 写"学完了某模块"不算，要写"能独立做什麼"。
