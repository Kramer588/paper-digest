# LEARNER-PROFILE-FORMAT.md

`LEARNER-PROFILE.md` 描述学习者**当前真实水平**，决定起点档位、教学语言、每课规模与反馈强度。没有它，按"零基础"处理。

## Template

```md
# Learner Profile

## 基本信息
- 方向/专业：{…}
- 目标：{读论文 / 写投稿 / 毕业课题 / 技术选型；时间点}
- 每周可投入：{小时}
- 语言：{中文讲解 + 英文样例？全英文？}

## 英语与写作
- 英语水平自评：{CET-4/6、雅思托福、能读摘要但慢、能写短句…}
- 英文写作经验：{没写过 / 写过实验报告 / 写过论文段落 / 投过稿}
- 最怕的写作环节：{开头 / 方法 / 结果 / 讨论 / 语法 / 词汇}

## 读论文经验
- 读过几篇英文论文：{0 / 1–5 / 6–20 / 20+}
- 能否读完 Methods：{能 / 跳读 / 不能}
- 是否会做笔记/复述：{会 / 不会}

## 背景知识
- 统计/编程/领域基础：{…}
- 已读过的关键文献：{…}

## 偏好与约束
- 偏好：{先看例子 / 先讲原理 / 要中文 / 要练习 / 不要一次太多}
- 限制：{时间碎片 / 网络 / 设备}

## 诊断结果（首次 [plan] 填写）
- 阅读起点：{R0 / R1 / R2}
- 写作起点：{W0 / W1 / W2}
- 当前最该补的 1 件事：{…}
- 下次会话：{…}
```

## Rules

- 首次会话用 6 个问题建立画像（英语写作经验、读论文数量、能否读完 Methods、目标、每周时间、偏好），不要一次问 20 个。
- 画像会变：每次 `[plan]` 或阶段结束时更新；变化大时写 `learning-records/` 记录原因。
- 不确定就按更低档处理：宁可第一课太简单（快速验证），不要一上来劝退。
- 画像只用于教学设计，不在产物里暴露隐私细节。
